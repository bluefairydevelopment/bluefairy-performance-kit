3-SENTENCE SUMMARY
------------------

BlueFairy Performance Kit removes the front-end weight WordPress adds whether
you use it or not: the emoji detection script and its stylesheet, the oEmbed
discovery links and wp-embed.js, and the heartbeat that polls admin-ajax for
visitors who will never see wp-admin. It also adds loading="lazy" to iframes in
post content, which WordPress does for images but not for embeds. Free,
GPL-2.0-or-later, PHP 8.1+, WordPress 6.4+; add BlueFairy Performance Kit Pro
when you want critical CSS, self-hosted Google Fonts and resource hints.


POSITIONING
-----------

This is a complete, honest free plugin, not a crippled demo. It does four things
properly and says plainly what it does not do.

Say "add Pro", never "upgrade to Pro". Pro is an add-on that runs alongside this
plugin and shares none of its features. "Upgrade" reads as a replacement, and a
customer who acts on that reading deactivates this plugin and loses all four
optimisations with nothing to tell them why.

SHORT DESCRIPTION (WooCommerce)
-------------------------------

Removes the emoji scripts, oEmbed JavaScript and front-end heartbeat WordPress
loads whether you use them or not, and lazy-loads iframes. Four switches, all on
by default, nothing to configure. Free and GPL.


WHAT THIS PLUGIN DOES NOT DO
----------------------------

State these plainly. They are the upgrade argument, and hiding them produces
refund requests.

- No critical CSS. Your stylesheets still block the first paint.
- No font handling. Google Fonts still come from Google.
- No resource hints, no LCP preload.
- No image work of any kind.

All four are in Pro. See COMPARISON.md for the table, and note that Pro is an
ADD-ON: it does not include the four features above, so a Pro customer needs
both plugins.
